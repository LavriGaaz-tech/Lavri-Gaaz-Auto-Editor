# Lavri_Gaaz Auto Editor v2

نسخة مطوّرة لبوت مونتاج بثوث YouTube الخاصة بك.

## ماذا تفعل v2؟
- مراقبة قناة YouTube واكتشاف الـVOD بعد انتهاء البث.
- تنزيل الـVOD تلقائيًا عبر yt-dlp.
- استخراج الصوت + تفريغ الكلام بالتوقيت عبر Whisper.
- حساب مؤشرات حماس من:
  - كلمات Gaming وردود الفعل.
  - ارتفاع مستوى الصوت.
  - سرعة/كثافة الكلام.
  - تكرار المؤشرات داخل نافذة زمنية.
- دمج المؤشرات بدل الاعتماد على كلمة واحدة فقط.
- منع اختيار لقطات متقاربة جدًا.
- إنشاء ملفات clips منفصلة.
- إنشاء Highlight طويل.
- إنشاء Shorts عمودية 9:16 مع تحويل تلقائي للصورة إلى الوسط.
- إضافة watermark باسم Lavri_Gaaz.
- إنشاء `edit_report.json` يوضح سبب اختيار كل لقطة ودرجتها.
- وضع إعدادات اللعبة والكلمات المهمة في `config.json`.

## متطلبات
يفضل Windows 10/11 أو Linux. Windows 7 غير موصى به مع إصدارات Python/Whisper الحديثة.

ثبّت:
- Python 3.10+
- FFmpeg
- حزم requirements.txt

ثم:
    python lavri_bot_v2.py

تجربة بث واحد:
    python lavri_bot_v2.py --video "https://www.youtube.com/watch?v=VIDEO_ID"

## تحسين الاختيار بالذكاء الاصطناعي
يمكن إضافة OpenAI API key في متغير البيئة:
    OPENAI_API_KEY=...

النسخة الأساسية لا تتطلب API key. تحليل الفيديو البصري المتقدم اختياري في v2.1.

## مهم
البوت مصمم للمحتوى الذي تملك حق تنزيله ومعالجته. لا ينشر الفيديو تلقائيًا إلى YouTube/TikTok في هذه النسخة؛ يحفظ النتائج لمراجعتك.
